# Ogilvy — Downloads

Verteil-Repo für [Ogilvy](https://github.com/schramm42/ogilvy): Releases und
`update-manifest.json` für das Autoupdate der Desktop-App.
Der Quellcode liegt in einem separaten, privaten Repository.

## Installation

Unter *Releases* die aktuelle `Ogilvy-amd64-installer.exe` laden.
Prüfsummen stehen in `SHA256SUMS`.
